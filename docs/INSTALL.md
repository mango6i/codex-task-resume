# 安装与使用

## 安装插件

需要 Windows、Python 3.10+、Codex CLI，以及支持本地插件的 Codex / ChatGPT Work 客户端。

1. 下载 [发行安装包](https://github.com/mango6i/codex-task-resume/releases) `codex-task-resume-1.0.zip`。
2. 解压到普通本地目录，完全退出客户端。
3. 运行包内 `install.cmd`，等待成功后重新打开客户端。
4. 打开插件详情的 **设置 → 统一管理 → 管理 Codex 任务续接**，或应用入口 **Codex 任务续接 · 管理**。

更新使用同样步骤，已有设置与运行记录会保留。也可以使用[本地助手安装提示词](INSTALL_WITH_CODEX.md)。

## 首次启用

在一个保留的本地控制对话中发送：

```text
使用 $quota-resume 初始化设置，保留我已保存的参数，暂不开启自动续接。
```

按客户端原生提示审核并信任检测脚本，再在设置面板明确开启自动续接并保存。在额度仍可用时，让控制对话建立原生恢复检查；在对话管理中确认排程记录。

只需一个控制对话，不需要在每个目标对话重复初始化。控制对话本身不会成为续接目标。

## 设置规则与范围

- **剩余额度阈值**：五小时额度严格低于该值时记录候选，默认 2%。
- **刷新后等待**：实际刷新时间之后的等待时长，默认 2 分钟。
- **续接提示词**：发送保存的原文，保留多行内容和换行。
- **检测最短间隔**：插件服务与任务事件共用查询节流，默认 60 秒。
- **范围**：自动记录运行任务并加入手动勾选目标，或只处理勾选的对话。

全选只覆盖当前已加载、匹配搜索且可选的对话；全选和清空只修改草稿，点击 **保存选择** 后生效。控制对话等不可选项会跳过。

## 阅读检测状态

| 显示 | 含义 |
| --- | --- |
| 已选对话 | 保存的允许处理范围 |
| 待续接 | 达到低额度条件后记录的候选 |
| 最近成功检测 | 最近一次成功读取额度的时间 |
| 服务已连接 | 检测服务存在近期心跳 |
| 任务事件时间 | 最近记录的活动；不是实时状态保证 |
| 续接排程 | 保存的恢复检查记录；执行前仍需原生核验 |

设置页的刷新时间来自账号额度接口。预计复查时间为实际刷新时间加等待时长；绿色保存提示显示的是设置保存时间，两者不同。

网络查询失败会重试一次。若保留近期成功数据，会明确标为历史数据；否则显示暂未获取。历史显示不能作为发送依据。

## 恢复与停止

恢复时会核对可用额度、等待时间、任务原生状态及上下文，只续接明确未完成且已停止的任务。仍运行、完成、暂停、等待输入或批准、归档和状态不明确的任务会跳过。发送结果不确定时不自动重发。

关闭自动续接开关并保存，可阻止后续发送。若要暂停原生检查，在控制对话发送：

```text
使用 $quota-resume 停止监控和自动续接。
```

## 必要限制

恢复检查需提前建立原生排程。额度耗尽前没有成功排程时，无法保证自动唤醒；后续额度周期也需正确重新排程。完整恢复周期仍待实际环境验证。

设置读写和本地只读额度检测不调用模型；建立排程、恢复检查与任务执行使用正常额度。客户端退出、服务断开或设备休眠后无法继续本地检测。不支持普通 ChatGPT 网页、云端任务、远程主机及子代理。

## 常见安装问题

**拒绝访问或缓存被占用**：完全退出客户端后重试。不要在安装未成功时删除原有插件目录。

**找不到 Python 或 Codex CLI**：先安装所缺依赖，再运行安装器。

**没有管理入口**：确认安装成功并重开客户端，检查插件服务是否连接。不同客户端的入口位置可能不同，可使用应用入口打开。
