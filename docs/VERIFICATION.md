# 验证范围

## 自动化行为检查

96 项 Python 测试覆盖设置的部分更新、并发保存、明确启用、候选记录、账号隔离、检测节流、禁用后的行为、发送预留与防重复，以及中英文资源。

新增回归覆盖选中但空闲的对话、旧额度失败、插件设置请求、任务轮次不符、过期活动、异步事件乱序、重新启用及不同窗口标识。只有捕获的同一轮工作明确因额度停止才能通过发送预留。

额度查询失败检查包括一次重试、历史数据期限与标记，并确认历史展示不修改捕获和发送状态。

排程回归覆盖只查看卡片但未启用、更新参数兼容性、暂停排程不能确认成功、过早或跨日唤醒、等待时长修改、原始恢复窗口、重复挂载及子代理排除。本机原生排程已完成启用、读取实际唤醒时间、暂停的往返验证；没有向项目发送测试消息。

控制对话的提示提交、工具完成、停止等事件不生成挂载指令；其他项目事件也不会在有效恢复检查刚唤醒时再次重排。过早唤醒仍允许按原始恢复时间修正排程。

兼容性回归覆盖 Stop 不创建新继续轮次、无关项目不接收挂载指令、Interrupt 不等待网络、旧界面资源入口、查询总超时、Windows 临时文件占用及损坏状态不扩大监控范围。

运行程序查找覆盖 PATH 缺失、客户端缓存与安装目录、旧路径失效、CLI 身份检查及明确的缺失提示。

排程不会额外固定等待五分钟；只按观察到的原生提前偏移修正并重新验证。恢复快照仅返回待续接候选，不输出完整发送历史，也不修改状态文件。

恢复提速回归覆盖仅查询已记录编号、同轮额度错误、已完成与手动暂停跳过、账号变化、原始等待时间、真实额度刷新、防重复预留，以及旧排程提示迁移。Node 原生工具执行程序检查发送顺序、换行原文、结果不明不重发、仅通过原生工具发送和检查后暂停。

首轮快速恢复暴露了 Windows 特殊引号传参错误：原生额度错误中的 `You’ve` 会提前结束 PowerShell 字符串。状态数据已改为 ASCII/Base64 传输，路径通过 ASCII JSON 还原。新增 Windows PowerShell 5.1 和 PowerShell 7 实际进程集成检查，运行真实持久化助手，覆盖特殊字符路径中的启动、同轮额度失败、发送前预留、多行原文、完成跳过和不确定发送不重试，共六组。桌面对话及发送工具使用隔离测试替身，不读取真实用户状态或向项目发测试消息。测试也检查空错误输出能明确定位到具体失败步骤。

2026-10-24 已观察到真实排程发送并确认目标新轮次运行。同一轮另一候选因实时额度接口读取失败未发送，不能将部分成功当作多任务恢复验收。现已补充同次检查内最多一次原生只读重试，错误包含具体操作及原生报错；发送和不确定结果从不重试。Node 回归重现“两项已记录、第一项首次读取额度失败”，确认恢复后两项均发送一次。两个 Windows shell 的真实持久化助手测试覆盖一次失败后恢复、持续失败保留队列和新鲜额度备用读取，共十二组。接口持续不可用时仍不发送，也不增加周期性模型检查。

本机复现只读额度请求连接失败；在同一子进程传入现有 Windows 系统代理后，真实额度读取成功且账号匹配。现已将代理继承修复用于额度子进程，明确配置的代理环境变量保持优先。原生额度查询持续失败时，只读额度备用读取只执行一次，仍经过原有账号、额度、真实刷新和等待校验。新增测试覆盖父进程环境不修改、明确空代理配置、非 Windows 行为、只读备用读取不访问任务状态，以及拒绝过期备用数据。任务状态核对、发送和发送预留均未更换后端。

上述测试不代表客户端必定准时唤醒，持续接口故障后的无人干预恢复仍未验证。

## 安装与界面检查

- 39 项安装与清理检查使用隔离目录及模拟原生安装器，覆盖成功校验、源码及缓存失败回滚、Python 路径绑定、目录边界和用户数据保留。
- 界面检查通过实际设置后端与模拟宿主联调，覆盖中文、英文、浅色、深色、小窗口和宽屏。
- 覆盖多行提示词原文保存、保存反馈、错误重试、外部项目链接、全选及清空只改草稿，以及不可选项的排除。
- 兼容只返回文本内容的工具结果；首次加载显示读取中，刷新失败保留原列表和勾选。
- 所有公开截图使用隔离示例数据。

## 尚未验证

已确认一次真实额度恢复后的原生预留、发送及目标新轮次启动；无人干预的完整周期和后续多周期仍未验收。模拟宿主检查不等于所有客户端版本均支持相同入口和弹窗。保存的排程记录也不证明未来执行一定成功。

运行测试：

```powershell
python -X utf8 -m unittest discover -s tests -v
node tests/test_native_dispatch.cjs
node tests/test_native_dispatch_windows.cjs python powershell.exe
```

有 PowerShell 7 时，可将其可执行文件路径追加到最后一条命令，以检查两个版本。
