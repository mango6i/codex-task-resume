# 验证范围

## 自动化行为检查

78 项 Python 测试覆盖设置的部分更新、并发保存、明确启用、候选记录、账号隔离、检测节流、禁用后的行为、发送预留与防重复，以及中英文资源。

新增回归覆盖选中但空闲的对话、旧额度失败、插件设置请求、任务轮次不符、过期活动、异步事件乱序、重新启用及不同窗口标识。只有捕获的同一轮工作明确因额度停止才能通过发送预留。

额度查询失败检查包括一次重试、历史数据期限与标记，并确认历史展示不修改捕获和发送状态。

排程回归覆盖实际触发早于允许时间、错误控制对话、误排到次日、漏检提示、暂停与未核验、等待时长修改、每周额度阻塞，以及健康额度时提前排程但不捕获或发送。原生排程元数据只读，不作为对话运行状态来源。

## 公告与重置停止检查

新增隔离测试覆盖原创帖解析、历史基线、重复或编辑帖去重、账号与时钟隔离、完整对话分页要求、完成项目的新检查、原文与模型参数、运行和阻塞排除、禁用后保留账本、真实双窗口全量重置与普通五小时刷新区分、停止优先、停止结果不确定时不重试及阻止后续启动、客户端断开、接口不支持时整批设置不变。

实际公开首页解析已读取到可核实的原创帖与 reset 正文。网页结构、登录要求和网络限制可能变化；失败不会作为触发依据。

新增自动控制仅对已开放且验证通过的原生共享控制通道生效。当前安装客户端未通过共享通道连接检查，因此不能在此环境声称群发与自动停止已完成真实端到端验收；其请求参数和持久状态转换使用隔离模拟接口验证。界面会阻止不支持的客户端启用，而不是降级到独立执行服务。

## 安装与界面检查

- 34 项安装与清理检查使用隔离目录及模拟原生安装器，覆盖成功校验、失败回滚、目录边界和用户数据保留。
- 界面检查通过实际设置后端与模拟宿主联调，覆盖中文、英文、浅色、深色、小窗口和宽屏。
- 覆盖多行提示词原文保存、保存反馈、错误重试、外部项目链接、全选及清空只改草稿，以及不可选项的排除。
- 所有公开截图使用隔离示例数据。

## 尚未验证

真实额度耗尽、刷新、原生唤醒及自动发送的完整周期尚未验收。模拟宿主检查不等于所有客户端版本均支持相同入口和弹窗。保存的排程记录也不证明未来执行一定成功。

运行测试：

```powershell
python -m unittest discover -s tests -v
```
