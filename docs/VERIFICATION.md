# 验证范围

本文件说明源码与界面已经检查的内容，不把隔离测试当成真实自动续接验收。

## 行为与安装

- 33 项 Python 行为测试覆盖参数读写、显式开启、并发部分更新、候选捕获、目标范围、取消勾选、账号改变时拒绝操作、发送前预留与防重复、资源白名单和状态区分。
- 安装与清理流程有 34 项隔离维护断言，覆盖更新成功后清理、失败恢复、同版本旧缓存拒绝、数据及其他插件保留、越界和链接路径拒绝，以及不将 Git 元数据复制进安装目录。
- 本地只读额度与对话元数据接口已探测；独立连接的运行状态不会被当成桌面任务的实时状态。
- 已有本机安装经过缓存文件内容比对与设置服务读取验证。发布源码使用可移植 Hook 命令；安装器根据目标机器生成 Python 路径。

## 界面

隔离宿主连接真实 Python 设置后端，使用示例对话与示例额度，检查：

- 原文多行保存、部分更新、撤销、输入校验及不意外开启监控。
- 初始连接失败 / 读取失败重试、键盘切换页签及草稿保留。
- 全局范围保存、勾选、搜索、控制对话不可选及未排程警示。
- 醒目的保存成功 / 失败提示、保存时间、继续修改时取消成功状态。
- 项目链接两种客户端打开方式，以及拒绝时的失败反馈。
- 浅色 / 深色三个页签，小窗口尺寸 920×640、640×480、390×480、320×360、390×320。
- 宽屏尺寸 1280×800、1600×900、1920×1000、2560×1200，内容居中、最大宽度、设置三栏、任务左右分栏与无横向溢出。

公开截图为隔离环境预览，不包含实际用户对话或账号状态。

## 尚未完成的验收

1. 真实额度耗尽、刷新、原生定时唤醒与向原对话发送的完整周期。
2. 额度已经耗尽且此前没有排程时，无需模型回合建立恢复排程的机制。
3. 不同客户端版本中原生管理按钮、弹窗和 Hook 信任入口的完整兼容性。

第三项受客户端提供的能力影响；前两项不能由“保存成功”或“已勾选对话”代替验证。

## 本次检测与语言修订

- 新增连接期间的模型外额度检测：共享查询租约、间隔节流、禁用后不再捕获、查询失败不入队、账号变化停用；单元测试使用隔离状态，不向真实对话发送。
- 设置页直接读取实际额度刷新时间，预计复查由接口时间加当前等待时长计算。保存提示明确写明保存时间不是刷新时间；失败清空旧显示。
- 对话页分开显示已选数量、候选数量、检测时间、服务心跳、最近任务事件和排程记录。历史“回合已结束”不等于任务完成，发送前必须原生复查。
- 全选仅覆盖当前已加载、匹配搜索且可选的对话；清空和全选只改草稿，保存后才生效。
- Windows 显示语言检测；中文变体映射到简体中文，其他语言到 English。英文资源、小窗口与宽屏检查通过，保存的中英文提示词原文未改变。
- 尚未完成真实额度耗尽、刷新、原生唤醒与逐条发送的完整周期验收。提前创建一个本机原生检查不证明未来周期会自动重新排程。

额度刷新网络失败修订：自动重试一次；有五分钟内同账号最近成功数据时显式标注为历史数据，超过期限显示友好失败提示；不将历史数据用于发送决策，不向用户暴露接口地址。
