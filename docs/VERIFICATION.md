# 验证范围

## 自动化行为检查

59 项 Python 测试覆盖设置的部分更新、并发保存、明确启用、候选记录、账号隔离、检测节流、禁用后的行为、发送预留与防重复，以及中英文资源。

新增回归覆盖选中但空闲的对话、旧额度失败、插件设置请求、任务轮次不符、过期活动、异步事件乱序、重新启用及不同窗口标识。只有捕获的同一轮工作明确因额度停止才能通过发送预留。

额度查询失败检查包括一次重试、历史数据期限与标记，并确认历史展示不修改捕获和发送状态。

排程回归覆盖只查看卡片但未启用、更新参数兼容性、暂停排程不能确认成功、过早或跨日唤醒、等待时长修改、原始恢复窗口、重复挂载及子代理排除。本机原生排程已完成启用、读取实际唤醒时间、暂停的往返验证；没有向项目发送测试消息。

控制对话的提示提交、工具完成、停止等事件不生成挂载指令；其他项目事件也不会在有效恢复检查刚唤醒时再次重排。过早唤醒仍允许按原始恢复时间修正排程。

## 安装与界面检查

- 34 项安装与清理检查使用隔离目录及模拟原生安装器，覆盖成功校验、失败回滚、目录边界和用户数据保留。
- 界面检查通过实际设置后端与模拟宿主联调，覆盖中文、英文、浅色、深色、小窗口和宽屏。
- 覆盖多行提示词原文保存、保存反馈、错误重试、外部项目链接、全选及清空只改草稿，以及不可选项的排除。
- 所有公开截图使用隔离示例数据。

## 尚未验证

真实额度耗尽、刷新、原生唤醒及自动发送的完整周期尚未验收。模拟宿主检查不等于所有客户端版本均支持相同入口和弹窗。保存的排程记录也不证明未来执行一定成功。

运行测试：

```powershell
python -m unittest discover -s tests -v
```
