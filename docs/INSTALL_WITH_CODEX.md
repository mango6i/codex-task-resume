# 让本地助手安装

在能访问本机文件的本地 Codex / ChatGPT Work 对话中，附上发行 ZIP，或提供文件的完整路径，然后发送：

```text
请帮我把提供的 Codex 任务续接安装包安装到当前本地客户端。先阅读包内安装说明并检查依赖，再运行包内安装器，保留已有设置。安装后核对插件和管理入口；需要重启或审核脚本时告诉我。暂不开启自动续接。
```

普通 ChatGPT 网页无法执行本机安装。依赖缺失、文件被占用或需要重启时，助手应说明具体问题；脚本信任由客户端原生流程处理。

## English

Attach the release ZIP, or provide its absolute local path, in a local Codex / ChatGPT Work chat with access to this computer:

```text
Install the Codex Task Resume package I provided into this local client. Read the bundled installation guide, check dependencies and run the installer. Preserve existing settings and verify the plugin and management entry. Tell me if a restart or hook review is needed. Leave automatic continuation disabled.
```

Ordinary ChatGPT web cannot install local software. The assistant should explain missing dependencies, locked files or a required restart. Hook trust uses the native client review flow.
